# Contact

Torso is an open source project, and it is run in the open on GitHub. That is the place to reach its maintainer, Julien Kollmann.

## Bugs and questions

Open an issue in the [issue tracker](https://github.com/julien1k/torso-cms/issues). For a bug, say which version of Next.js you use, whether you build with Turbopack or webpack, and what you clicked or saved when it went wrong. A small example that shows the problem helps most.

Before you write, the [docs](/docs) have a troubleshooting section, and the [status page](/status) lists the limits that are already known.

## Changes to the code

Pull requests are welcome in the [repository](https://github.com/julien1k/torso-cms). For anything larger than a small fix, open an issue first so the approach can be agreed before you spend time on it.

## Security problems

If you find a way for an editor to write something they should not be able to, or for someone to edit without being allowed to, report it privately through GitHub's "Report a vulnerability" option on the repository's Security tab, not in a public issue.
